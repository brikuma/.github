# Contributing

Propose changes through a pull request. Maintain English copy, accessible image descriptions and a clear distinction between the product vision and the frontend prototype. Use a GitHub noreply commit email.

Follow [privacy setup](PRIVACY.md). Run `python3 -B scripts/docs-check.py`, `python3 -B scripts/privacy_test.py` and `python3 -B scripts/github_policy_test.py`. Review the exact staged tree before committing. Use an English Conventional Commit such as `docs(docs): update the organization profile`.

The required checks are `privacy` and `docs-required-gate`. Only designated maintainers can merge; independent approvals are not mandatory during the solo-maintainer phase. Original contributions use MIT.
