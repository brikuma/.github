# BRIKUMA

A design studio for turning ideas into models made of interlocking construction bricks.

Start with an empty canvas or a reference. Shape a model, revise its parts and keep the design, inventory and instructions connected. BRIKUMA explores how manual building and assisted design can work together while keeping the builder in control.

[Explore the project](https://github.com/brikuma/brikuma) · [Run the frontend](https://github.com/brikuma/brikuma-frontend#readme) · [Contribute](https://github.com/brikuma/brikuma/blob/main/CONTRIBUTING.md)

## The idea

A useful brick model has to balance its subject with the pieces, space, cost and complexity available. The goal is to help people make those design decisions: preserve the details that matter, try alternatives, protect work they want to keep and understand what each change affects.

The wider vision connects free-form building, reference images and briefs, assisted edits, parts inventories, readable instructions and collaboration. Models, quantities and instructions should describe the same revision. Checks should say what was tested and what remains unverified.

## What you can try today

The current release is an early frontend prototype that runs locally in your browser:

- Build from an empty scene or explore original demo models.
- Place, move, rotate, recolor and group supported parts, with undo and redo.
- Inspect a model, its quantities and local instruction drafts.
- Save projects in the browser and download portable project files and PNG views.

AI assistance is a labeled, pre-authored preview. Cloud sync, live collaboration, purchases and physical build validation are future work. The demo part library is original geometry, not a verified commercial parts catalog.
